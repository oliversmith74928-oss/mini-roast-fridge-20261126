## The line

> My fridge's freezer is so full of forgotten leftovers that archaeologists could carbon-date my last three diets.

112 characters (113 with the trailing newline), within the 200-character limit.

## How it works

`main.py` (Python standard library only) writes exactly that one line to
`/output/entry.txt`. Run it twice and the output is byte-identical.

```sh
python3 main.py
cat /output/entry.txt
```
